# Landing page — Culto dos Adolescentes (AD1)

Landing page do culto dos adolescentes da Primeira Igreja Batista de João Pessoa (AD1).
Site estático: `index.html`, `style.css`, `script.js` e `assets/`.

## Rodar localmente

```bash
python3 -m http.server 8202
```

Abra http://localhost:8202.

## Editar dados

- Horário, local e contato: seção `#visita` em `index.html`.
- WhatsApp do botão: constante `WHATSAPP` em `script.js`.
